# Additional Nodes

These nodes are not direct objects in Entra ID or Azure but are created as a result of ingesting other types of nodes.

## Node Types

- **[Certificate](additional-nodes/certificate.md)** - X.509 certificates used for authentication
- **[ClientSecret](additional-nodes/client-secret.md)** - Client secrets used for application authentication  
- **[IPConfig](additional-nodes/ip-config.md)** - IP configuration details for network interfaces
- **[NSGRule](additional-nodes/nsg-rule.md)** - Network security group rules
- **[Subnet](additional-nodes/subnet.md)** - Virtual network subnets
- **[VerifiedDomain](additional-nodes/verified-domain.md)** - Verified domains for Azure AD organizations
