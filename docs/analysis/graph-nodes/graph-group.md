# GraphGroup

Represents Azure AD groups collected from Microsoft Graph.

**Labels:** `:GraphObject:GraphGroup`

**Properties:**

- `displayName` - Group's display name
- `groupTypes` - Array of group types
- `membershipRule` - Dynamic membership rule (if applicable)
- `membershipRuleProcessingState` - Processing state of membership rule
- `onPremisesSecurityIdentifier` - On-premises security identifier
- `organizationId` - Organization identifier
- `securityEnabled` - Whether the group is security-enabled
- `visibility` - Group visibility (Public, Private, etc.)
