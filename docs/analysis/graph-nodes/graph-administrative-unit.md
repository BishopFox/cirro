# GraphAdministrativeUnit

Represents Entra ID administrative units collected from Microsoft Graph.

**Labels:** `:GraphObject:GraphAdministrativeUnit`

**Properties:**

- `description` - Administrative unit description
- `displayName` - Administrative unit display name
- `isMemberManagementRestricted` - Whether member management is restricted
- `membershipRule` - Dynamic membership rule
- `membershipRuleProcessingState` - Processing state of membership rule
- `membershipType` - Type of membership (Assigned, Dynamic)
- `visibility` - Administrative unit visibility
