# GraphDevice

Represents Entra ID devices collected from Microsoft Graph.

**Labels:** `:GraphObject:GraphDevice`

**Properties:**

- `displayName` - Device display name
- `accountEnabled` - Whether the device account is enabled
- `deviceId` - Device identifier
- `isCompliant` - Whether the device is compliant
- `isManaged` - Whether the device is managed
- `manufacturer` - Device manufacturer
- `model` - Device model
- `onPremisesLastSyncDateTime` - Last sync date/time with on-premises
- `onPremisesSyncEnabled` - Whether on-premises sync is enabled
- `operatingSystem` - Operating system
- `operatingSystemVersion` - Operating system version
- `profileType` - Device profile type
- `trustType` - Device trust type
