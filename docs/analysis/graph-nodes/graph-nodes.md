# Graph Nodes

<h2>GraphObject (Base Label)</h2>

All Microsoft Graph entities inherit from the base `GraphObject` label and include the `id` property.

**Common Properties:**

- `id` - Unique identifier (primary key)

## Node Types

- **[GraphAdministrativeUnit](graph-administrative-unit.md)** - Administrative units for delegated administration
- **[GraphApplication](graph-application.md)** - Azure AD applications  
- **[GraphDevice](graph-device.md)** - Devices registered in Azure AD
- **[GraphGroup](graph-group.md)** - Security and distribution groups
- **[GraphOrg](graph-organization.md)** - Azure AD organizations/tenants
- **[GraphRole](graph-role.md)** - Directory roles and permissions
- **[GraphServicePrincipal](graph-service-principal.md)** - Service principals for applications
- **[GraphUser](graph-user.md)** - User accounts and identities
