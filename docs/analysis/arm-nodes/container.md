# Container Resources

Azure container-related resources including container registries.

## ContainerRegistry

Represents Azure Container Registry instances.

**Labels:** `:ArmResource:ContainerRegistry`

**Properties:**

- `id` - Container registry resource ID (primary key)
- `sku` - SKU name
- `adminUserEnabled` - Admin user enabled
- `anonymousPullEnabled` - Anonymous pull enabled
- `creationDate` - Registry creation date
- `dataEndpointEnabled` - Data endpoint enabled
- `dataEndpointHostNames` - Data endpoint host names
- `loginServer` - Login server URL
- `metadataSearch` - Metadata search setting
- `networkRuleBypassOptions` - Network rule bypass options
- `publicNetworkAccess` - Public network access setting
- `createdAt` - System creation timestamp
- `createdBy` - Created by user
- `createdByType` - Created by type
- `lastModifiedAt` - Last modification timestamp
- `lastModifiedBy` - Last modified by user
- `lastModifiedByType` - Last modified by type
