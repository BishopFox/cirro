# Cognitive Services

Azure Cognitive Services resources for AI and machine learning capabilities.

## CognitiveServicesAccount

Represents Azure Cognitive Services accounts.

**Labels:** `:ArmResource:CognitiveServicesAccount`

**Properties:**

- `id` - Cognitive services account resource ID (primary key)
- `customSubdomain` - Custom subdomain name
- `endpoint` - Service endpoint URL
- `publicNetworkAccess` - Public network access setting
