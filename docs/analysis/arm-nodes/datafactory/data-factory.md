# DataFactory

Represents Azure Data Factory instances.

**Labels:** `:ArmResource:DataFactory`

**Properties:**

- `id` - Data Factory resource ID (primary key)
- `createTime` - Factory creation timestamp
- `publicNetworkAccess` - Public network access setting
- `version` - Factory version
- `repoAccountName` - Repository account name
- `repoBranch` - Repository collaboration branch
- `repoDisablePublish` - Whether publishing is disabled
- `repoHostname` - Repository hostname
- `repoLastCommitId` - Last commit ID
- `repoName` - Repository name
