# SaasResource

Represents Azure Marketplace SaaS (Software as a Service) resources.

**Labels:** `:ArmResource:SaasResource`

**Properties:**

- `id` - SaaS resource ID (primary key)
- `beneficiaryEmail` - Email of the resource beneficiary
- `created` - Creation timestamp
- `lastModified` - Last modification timestamp
- `offerId` - Marketplace offer ID
- `offerName` - Marketplace offer name
- `publisherId` - Publisher ID
- `publisherName` - Publisher name
- `purchaserEmail` - Email of the purchaser
- `saasResourceName` - Name of the SaaS resource
- `saasSubscriptionId` - SaaS subscription ID
- `status` - Current status of the SaaS resource
- `storeFront` - Store front information
