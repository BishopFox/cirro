# Network Resources

Azure networking resources including virtual networks, network interfaces, security groups, and DNS.

## Resource Types

- **[VirtualNetwork](network/virtual-network.md)** - Azure virtual networks
- **[NetworkInterface](network/network-interface.md)** - Network interfaces attached to VMs
- **[PublicIPAddress](network/public-ip-address.md)** - Public IP addresses
- **[NSG](network/nsg.md)** - Network security groups and their rules
- **[DNSZone](network/dns-zone.md)** - DNS zones
- **[Subnet](network/subnet.md)** - Subnets within virtual networks
- **[IPConfig](network/ip-config.md)** - IP configurations for network interfaces
- **[NSGRule](network/nsg-rule.md)** - Network security group rules
