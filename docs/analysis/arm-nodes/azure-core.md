# Azure Core Resources

Core Azure infrastructure resources including tenants, subscriptions, and resource groups.

## Resource Types

- **[Tenant](azure-core/tenant.md)** - Azure tenants - the top-level organizational units
- **[Subscription](azure-core/subscription.md)** - Azure subscriptions - billing and management units
- **[ResourceGroup](azure-core/resource-group.md)** - Azure resource groups - logical containers for resources
- **[Generic ARM Resource](azure-core/arm-resource.md)** - Base properties inherited by all ARM resources
