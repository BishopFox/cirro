# ClassicStorageAccount

Represents classic (legacy) Azure storage accounts.

**Labels:** `:ArmResource:ClassicStorageAccount`

**Properties:**

- `id` - Classic storage account resource ID (primary key)
- `accountType` - Account type
- `creationTime` - Creation timestamp
- `geoPrimaryRegion` - Geographic primary region
- `geoSecondaryRegion` - Geographic secondary region
- `statusOfPrimaryRegion` - Status of primary region
- `statusOfSecondaryRegion` - Status of secondary region
