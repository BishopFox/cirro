# PrivateDnsZone

Represents Azure private DNS zones.

**Labels:** `:ArmResource:PrivateDnsZone`

**Properties:**

- `id` - Private DNS zone resource ID (primary key)
- `internalId` - Internal ID
- `numberOfRecordSets` - Number of record sets
- `numberOfVirtualNetworkLinks` - Number of virtual network links
- `numberOfVirtualNetworkLinksWithRegistration` - Number of virtual network links with registration
