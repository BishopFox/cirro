# IS_DEPLOYED

Links resources to their deployment configurations or associated infrastructure components.

**Relationship:** `:IS_DEPLOYED`

**Direction:** Various (depends on the specific resource types being linked)

## Description

This relationship indicates that one resource is deployed to or configured with another resource, typically representing deployment relationships or infrastructure associations.

## Examples

### NetAppAccount → NetAppAccountADDomain
Links NetApp accounts to their Active Directory domain configurations, indicating that the account is deployed with specific AD integration settings.

## Use Cases

- Understanding deployment relationships between resources
- Mapping infrastructure dependencies and configurations
- Identifying how services are integrated with identity and authentication systems
