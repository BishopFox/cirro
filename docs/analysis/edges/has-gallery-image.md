# HAS_GALLERY_IMAGE

Links galleries to their contained images.

**Relationship:** `:HAS_GALLERY_IMAGE`

**Direction:** `Gallery` → `GalleryImage`

## Description

This relationship connects Azure Compute Galleries to the images they contain, representing the organizational structure of shared compute images.

## Use Cases

- Understanding which images are available in specific galleries
- Organizing and managing compute image resources
- Identifying image repositories and their contents
