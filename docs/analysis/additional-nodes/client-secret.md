# ClientSecret

Represents client secrets for applications and service principals.

**Labels:** `:ClientSecret`

**Properties:**

- `keyId` - Key identifier (primary key)
- `customKeyIdentifier` - Custom key identifier
- `displayName` - Secret display name
- `startDateTime` - Start date/time
- `endDateTime` - End date/time
- `hint` - Password hint
- `secretText` - Secret text (if available)
