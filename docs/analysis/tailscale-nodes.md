# Tailscale Nodes

These nodes represent entities within a Tailscale network that are discovered through the Tailscale API.

## Node Types

- **[TSUser](tailscale-nodes/ts-user.md)** - Tailscale users who can own devices
- **[TSDevice](tailscale-nodes/ts-device.md)** - Devices connected to the Tailscale network
- **[TSTailnet](tailscale-nodes/ts-tailnet.md)** - Tailscale network instances
